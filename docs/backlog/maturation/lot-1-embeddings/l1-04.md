# [l1-04] — CHAPEAU : le banc

> **Fiche chapeau : elle ne se dispatche pas.** Révisée post-revue v1 (scission de
> `l1-04.3`, rapport réorienté après la campagne).

## Contexte

⭐ Pas d'achat matériel (décision Philippe) : le banc décide d'un **périmètre** — combien de
chips, de sites, de mois sont embeddables sur cette machine, et quels **leviers** permettent
d'en embedder plus avant de renoncer. Un banc qui constate une lenteur sans mesurer de
levier ne décide rien.

## Décisions portées par ce chapeau (ne pas rouvrir)

1. ⭐ **Chargement, forward et écriture chronométrés SÉPARÉMENT** (`l1-04.1`, qui précède
   tous les leviers) — sinon on attribue au GFM un coût qui est celui de l'I/O, et tous les
   leviers portent à faux.
2. **Chaque levier rend un chiffre ou une raison motivée de ne pas conclure.**
3. **Le banc écrit du JSON** ; le rapport (`l1-04.5`) agrège, il ne mesure jamais.
4. **Aucun seuil de succès sur les temps** : le banc publie, `l1-06.H` arbitre.
5. ⭐ **Le rapport vient APRÈS la campagne** (revue K-06) : c'est lui qui porte le **ratio
   discrimination / seconde** — critère de sortie n°5 du lot — et la confrontation durée
   réelle ↔ extrapolation. Il dépend donc de `l1-05.3.H`.
6. **ONNX est autorisé comme mesure jetable** (arbitrage Philippe) : onnxruntime peut être
   installé dans l'environnement de mesure, mais n'entre PAS au contrat du paquet.

## Ce qu'on sait déjà (revue v1 — dénombrements, pas des mesures)

- **Clay-large ~302 M params / 1024 tokens contre TerraMind-small ~21 M / 256 tokens** :
  rapport de coût attendu ~**50×**, dominé par la taille de modèle AUTANT que par les
  tokens. L'asymétrie est subie (pas d'autre variante Clay v1.5) et déclarée au chapeau
  `l1-02`.
- Le corpus (~16 Gio) est lu à travers **drvfs** — taxe déjà mesurée au Lot 0.
- Le parallélisme est une **contention** ici (goulot CPU), pas un multiplicateur.

## Politique de test (rappel)

Un banc n'a presque pas besoin de tests : l'instrumentation doit prouver qu'elle **compte ce
qu'elle prétend compter**, le rapport doit savoir **rendre rouge** un levier non concluant.

⚠ ⭐ **Deux propriétés du harnais que « script de mesure » ne dispense pas** (revue v4) :
**`mypy --strict` couvre `scripts/`** (`pyproject.toml:146` — `files = ["src", "tests",
"scripts"]`), donc les cinq scripts de banc s'annotent comme du code de production ; et
**`assert` y déclenche `S101`** sauf exemption — `l1-00` la pré-pose pour
`scripts/bench_*.py`, ce qui rend exécutables les oracles qui exigent « vérifié **dans** le
script ». Sans cette ligne, `just lint` serait rouge sur les cinq fiches.
Le reste, ce sont des mesures — elles se publient.
