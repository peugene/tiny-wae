# [l0-03.5] — Le harnais de rejeu et le smoke

## Objectif

Rendre `just check` déterministe et hors ligne (D-a), et livrer le chemin live. Cette
fiche REMPLACE `scripts/smoke.py` — le gate lui appartient.

## Périmètre (fichiers nommés)

- **Enregistrement des fixtures** : `scripts/record_fixtures.py` (rejouable, réseau) —
  télécharge et CLIPPE localement les fenêtres des items gelés (chapeau l0-02 : le clair
  2024, le nuageux 2023, le S2C) + **la fenêtre complète A01 × sept. 2022 (6 items,
  mesuré)** pour l0-04.1/l0-05 → GeoTIFF locaux sous `tests/fixtures/cog/` (~2-5 Mo,
  versionnés) + enveloppes JSON correspondantes sous `tests/fixtures/stac/`.
- `src/tiny_wae/adapters/fixture_source.py` : `FixtureSource(StacSource)` — sert les
  enveloppes enregistrées, hrefs `file://` vers les GeoTIFF locaux. AUCUN mock HTTP.
- **Smoke** : `scripts/smoke.py` réécrit — mode `--replay` (défaut) : `ingest` complet via
  FixtureSource sur l'item clair, assertions (3 fichiers, tailles, hashes attendus gravés,
  manifeste conforme) ; mode `--live` : même chemin via EarthSearchSource, data_root
  temporaire, hors gate. `just check` inchangé dans sa forme (`just smoke` = replay).
- ⭐ **Garde réseau — amendement à D-a (décision Philippe E-b, 21/08)**. Le mécanisme de
  rejeu ne change pas ; **la garde passe du TRANSPORT au CONTRAT**, pour la raison
  suivante, **mesurée** en revue v3 : `pytest-socket`/monkeypatch patchent le module
  `socket` de Python, mais rasterio lit via **GDAL (C, libcurl)** qui ne l'emprunte
  jamais — `rasterio.open("https://…")` sous `disable_socket()` **atteint le réseau**.
  Le risque réel est donc le **faux-vert** : un smoke qui passe en téléchargeant.
  - **Bretelles (garde de contrat, la vraie)** : mode `TINY_WAE_OFFLINE=1` posé par
    `smoke --replay` (et hérité par `just check`). Sous ce mode, **`adapters/chips.py`**
    refuse d'ouvrir tout href dont le schéma n'est pas `file://` → exception typée
    `RemoteAccessForbidden`. ⚠ La garde vit dans **`chips.py`** (celui qui OUVRE), pas
    seulement dans `FixtureSource` (qui ne fait que servir des hrefs) : tout autre chemin
    d'appel reste ainsi couvert.
  - **Ceinture (garde de transport, partielle et assumée)** : `pytest-socket` continue de
    couvrir le chemin **STAC** (`httpx`/`pystac-client`, qui passent bien par le `socket`
    Python). Écrire dans la fiche qu'il **ne couvre pas** les lectures GDAL — pour que
    personne ne croie qu'un seul dispositif suffit.
- Mesures live publiées (volume/durée/octets par chip — baseline pour l0-04).

## Définition de « terminé »

- [ ] Fixtures enregistrées et commises ; FixtureSource ; smoke 2 modes ; `just check`

      test unitaire dédié ; la limite de `pytest-socket` (ne couvre pas GDAL) écrite dans
      le docstring du smoke.
