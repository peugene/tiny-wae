# [l0-03.5] — Corpus de fixtures et FixtureSource

> Scission de l'ex-l0-03.5 (PO, 21/08 — elle cumulait un script d'enregistrement réseau
> **jetable** et le **gate permanent**, deux natures et deux rythmes de vie différents,
> sur le point de passage unique du graphe). **Ici : le corpus.** Le smoke est en l0-03.7.
> Mise en œuvre de **D-a**.

## Objectif

Constituer le matériau qui rend tous les tests aval déterministes et hors ligne : des
GeoTIFF locaux clippés + les enveloppes STAC correspondantes, servis par une
implémentation du port `StacSource`.

## Périmètre (fichiers nommés)

- **`scripts/record_fixtures.py`** (rejouable, RÉSEAU, hors package) — télécharge et
  **clippe** les fenêtres utiles :
  - les **3 items gelés** du chapeau l0-02 (clair `S2A_31TGJ_20240801_0_L2A`, nuageux
    `S2B_31TGJ_20230315_0_L2A`, S2C `S2C_31TGJ_20260513_0_L2A`) ;
  - un item **`sequence=1`** (candidat mesuré : `S2A_31TGJ_20260813_1_L2A`) ;
  - la **fenêtre A01 × 1 mois** (6 items, mesuré) pour l0-04.1 ;
  - un **second site** (B09 A69, mono-tuile, 3 items suffisent) — exigé par les oracles
    multi-sites de l0-04.1/O2 et l0-05.2/O3/O5, que l'ex-fiche déclarait « non couverts ».
  ⚠ **Adressage par ID et par fenêtre ABSOLUE**, jamais « 48 mois glissants » : deux des
  items gelés sortiront de la fenêtre glissante (le nuageux le 15/03/2027) — le script
  doit rester rejouable après cette date.
- Sortie : `tests/fixtures/cog/` (GeoTIFF clippés) + `tests/fixtures/stac/` (enveloppes
  JSON, réutilise le format de l0-02.1). ⭐ **Budget mesuré : ~2,84 MiB brut par item →
  ~14 items ≈ 40 MiB brut, ~20 MiB en DEFLATE** (l'ex-fiche annonçait « 2-5 Mo », faux
  d'un facteur 5-10). Si le dépôt s'en trouve trop lourd : réduire les fenêtres des items
  non-smoke à 128×128, décision à prendre **à la mesure**, pas d'avance.
- **`src/tiny_wae/adapters/fixture_source.py`** : `FixtureSource(StacSource)` — sert les
  enveloppes enregistrées, hrefs `file://` vers les GeoTIFF locaux. **AUCUN mock HTTP.**
- Dépendances : déjà posées par l0-01.1 (`rasterio`, `httpx`). `pixi.lock` : versionné,
  jamais mergé.

## Définition de « terminé »

- [ ] `record_fixtures.py` + corpus enregistré et commis (2 sites, ≥ 14 items).
- [ ] `FixtureSource` + tests de contrat (sert les mêmes types que `EarthSearchSource`).
