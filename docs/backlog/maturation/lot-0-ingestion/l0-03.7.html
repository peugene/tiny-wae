[l0-03.7] — Le gate : smoke deux modes + garde de contrat

Seconde moitié de la scission de l'ex-l0-03.5 (PO, 21/08). Ici : le gate permanent — le corpus qu'il consomme est livré par l0-03.5. Met en œuvre E-b (garde de contrat) et remplace le smoke minimal posé par l0-03.4.

Objectif

Rendre just check déterministe, hors ligne et capable de rougir ; livrer le chemin live et ses mesures.

Périmètre (fichiers nommés)

  • scripts/smoke.py réécrit (il remplace le smoke minimal de l0-03.4) :
  • --replay (défaut, câblé dans just check) : ingest complet via FixtureSource sur l'item clair gelé ; assertions — 3 fichiers, manifeste conforme, content_hashes == valeurs gravées, assets_read > 0.

  • ⭐ Garde réseau de CONTRAT — décision E-b. Le mode --replay pose TINY_WAE_OFFLINE=1 ; sous cette variable, adapters/chips.py (l0-03.3) refuse tout href non-file:// → RemoteAccessForbidden, levée avant ouverture. ⚠ Motif mesuré en revue v3 : pytest-socket patche le socket Python, mais rasterio lit via GDAL/libcurl (C) — une garde de transport laisserait le smoke passer VERT en téléchargeant (faux-vert, le vrai danger). pytest-socket reste en ceinture pour le seul chemin STAC ; écrire cette limite dans le docstring du smoke.
  • justfile : just smoke = --replay (forme inchangée).

Définition de « terminé »

  • [ ] Smoke 2 modes ; garde de contrat opérationnelle ; just check vert hors ligne.
  • [ ] Limite de pytest-socket (ne couvre pas GDAL) écrite dans le docstring.
