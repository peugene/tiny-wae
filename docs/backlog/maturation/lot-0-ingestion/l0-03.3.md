# [l0-03.3] — Chips : lecture et écriture

## Objectif

Depuis une `Acquisition` : lire les fenêtres nécessaires (SCL d'abord), écrire les 3
fichiers sur la grille du site. Pas de CLI ici (l0-03.4), pas de manifeste (fonction pure
retournant un résultat que l0-03.4 assemble).

## Périmètre (fichiers nommés)

- `src/tiny_wae/adapters/chips.py` :
  - `read_scl(acq, grid) -> ndarray 256×256` — fenêtre dérivée **ici** de
    `core.geometry.chip_bounds` (l0-03.1) via `rasterio.windows.from_bounds` sur le
    transform de la source ; `Resampling.nearest`
    si jamais nécessaire — normalement AUCUN rééchantillonnage, fenêtre entière.
  - `read_bands_10m(acq, grid)`, `read_bands_20m(acq, grid)` — 4 et 6 bandes (D-b :
    rededge1/2/3 + nir08 + swir16 + swir22), dans CET ordre, gravé en constante
    `BAND_ORDER_10M` / `BAND_ORDER_20M` (l'ordre des bandes est un contrat du Lot 1).
  - `write_chips(dest_dir, arrays, grid)` : **GeoTIFF simple, PAS COG (G5)**, uint16,
    transform de `core.geometry.transform_for`, tags (item_id, band order).
  - Garde : `acq.proj_epsg == grid.epsg` sinon exception typée (→ `failed`/`tile_mismatch`
    dans l0-03.4). ⭐ **Compteur `assets_read`** exposé (décision E-d) : nombre
    d'ouvertures de raster effectuées par ce module — l'instrument d'idempotence du lot.
    Pas de comptage d'octets ici (les lectures passent par GDAL, non instrumentable).
  - ⭐ **Garde réseau de contrat (décision E-b, 21/08)** : sous `TINY_WAE_OFFLINE=1`,
    **refuser tout href dont le schéma n'est pas `file://`** → exception typée
    `RemoteAccessForbidden`, levée **AVANT toute ouverture** (aucune requête émise).
    C'est ICI qu'elle vit — `chips.py` est le seul point qui ouvre les rasters ; la
    placer dans `FixtureSource` seul serait contournable. ⚠ Motif mesuré en revue v3 :
    `pytest-socket` ne couvre PAS les lectures GDAL (C/libcurl), donc une garde de
    transport laisserait passer un smoke « vert en téléchargeant ».
- Dépendance utilisée : `rasterio` — **déjà posée par l0-01.1** (ne pas toucher au
  `pyproject.toml`). `pixi.lock` : versionné, jamais mergé — régénérer au besoin.
- Tests : sur les GeoTIFF fixtures locaux de l0-03.5 s'ils existent déjà, SINON sur des
  rasters synthétiques écrits par le test (les deux marchent — ne pas attendre l0-03.5).
