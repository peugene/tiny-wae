## Décisions portées (ne pas rouvrir)

- Marge incrémentale **3 jours** (`incremental_margin_days`, settings de l0-01.1) —
  dérivation : latence de publication mesurée, largement inférieure au jour.
- **Rattrapage mensuel documenté, non automatisé** au POC (`backfill --months 2`) : les
  retraitements tardifs (`sequence ≥ 1`) échappent structurellement à la fenêtre.
- **Ordonnancement (cron) = geste d'infra Philippe**, hors fiches : les CLIs sont
  rejouables et idempotents, la commande type est documentée au README.
- Le recouvrement dû à la marge est absorbé par l'idempotence de l0-03.4 (`grid_hash`).

## Contexte

Le run quotidien « quoi de neuf ? ». Prémisses corrigées par les revues : revisite réelle
2,1-4,6 j selon site (comptage par tuile) → ~8-12 nouvelles acquisitions/jour sur le parc,
les runs ne sont pas « souvent vides ». Latence de publication ~3-5 h → marge 3 j
(`incremental_margin_days`) confortable. Les retraitements tardifs (`sequence≥1`)
échappent à la fenêtre : rattrapage mensuel documenté (`backfill --months 2`), non
automatisé au POC. Le cron réel = geste d'infra Philippe, hors fiches.
