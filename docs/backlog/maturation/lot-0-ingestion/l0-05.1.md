# [l0-05.1] — Bornes update

## Objectif

Calculer la fenêtre du run incrémental d'un site, à sec.

## Périmètre (fichiers nommés)

- `src/tiny_wae/core/update_bounds.py` : `update_window_for_site(last_datetime,
  margin_days, now) -> Window | NoManifests` — borne basse = `last_datetime − margin`,
  borne haute = `now` (paramètre, horloge injectable) ; site sans manifeste → valeur
  typée `NoManifests` (le CLI en fera un exit 1 pointant vers backfill).
  (`core/windows.py` de l0-03.1 porte déjà la primitive — cette fiche la spécialise ;
  si tout tient dans windows.py, l'y mettre et le dire au Résumé.)
- Tests à sec sur manifestes fixtures (corpus l0-03.2) : dernier jour, marge, site vierge,
  statuts rejetés comptés dans `last_datetime`.

## Définition de « terminé »

- [ ] Fonction + tests, docstring avec la dérivation de la marge (latence mesurée ~3-5 h,
      marge 3 j, recouvrement absorbé par l'idempotence).
