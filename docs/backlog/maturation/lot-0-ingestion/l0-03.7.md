# [l0-03.7] — Le gate : smoke deux modes + garde de contrat

> Seconde moitié de la scission de l'ex-l0-03.5 (PO, 21/08). **Ici : le gate permanent** —
> le corpus qu'il consomme est livré par l0-03.5. Met en œuvre **E-b** (garde de contrat)
> et remplace le smoke minimal posé par l0-03.4.

## Objectif

Rendre `just check` déterministe, hors ligne et **capable de rougir** ; livrer le chemin
live et ses mesures.

## Périmètre (fichiers nommés)

- `scripts/smoke.py` réécrit (il remplace le smoke minimal de l0-03.4) :
  - **`--replay` (défaut, câblé dans `just check`)** : `ingest` complet via
    `FixtureSource` sur l'item clair gelé ; assertions — 3 fichiers, manifeste conforme,
    `content_hashes` == valeurs gravées, `assets_read > 0`.
  - **`--live`** (hors gate) : même chemin via `EarthSearchSource`, `data_root`
    temporaire ; publie les **mesures** (durée et octets écrits par chip — baseline
    attendue par l0-04).
- ⭐ **Garde réseau de CONTRAT — décision E-b.** Le mode `--replay` pose
  `TINY_WAE_OFFLINE=1` ; sous cette variable, `adapters/chips.py` (l0-03.3) refuse tout
  href non-`file://` → `RemoteAccessForbidden`, levée **avant ouverture**.
  ⚠ Motif **mesuré** en revue v3 : `pytest-socket` patche le `socket` Python, mais
  rasterio lit via **GDAL/libcurl (C)** — une garde de transport laisserait le smoke
  passer **VERT en téléchargeant** (faux-vert, le vrai danger). `pytest-socket` reste en
  ceinture pour le seul chemin STAC ; **écrire cette limite** dans le docstring du smoke.
- `justfile` : `just smoke` = `--replay` (forme inchangée).

## Définition de « terminé »

- [ ] Smoke 2 modes ; garde de contrat opérationnelle ; `just check` vert hors ligne.
- [ ] Limite de `pytest-socket` (ne couvre pas GDAL) écrite dans le docstring.

## Oracle / recette

| # | Critère | Seuil |
|---|---|---|
| O1 | `just smoke` (replay), machine hors ligne | vert ; `content_hashes` == valeurs gravées ; `assets_read > 0` |
| O2 | Cas négatif : une fixture retirée | ROUGE, STDERR nomme **le chemin du fichier manquant** (assertion littérale) |
| O3 | **Garde de contrat** : fixture dont un href est `https://`, sous `TINY_WAE_OFFLINE=1` | ROUGE, exit ≠ 0, cause **`RemoteAccessForbidden`** nommée ; **aucune requête émise** (l'exception précède l'ouverture) |
| O3bis | Même fixture, `TINY_WAE_OFFLINE` absent | l'ouverture est tentée normalement (la garde n'est pas un blocage permanent) |
| O4 | **Répétabilité** : `just smoke` deux fois, `data_root` vierge à chaque fois | `content_hashes` identiques ; `assets_read > 0` aux deux |
| O5 [live, hors gate] | `smoke --live` avant livraison | vert ; **durée et octets écrits par chip publiés** dans le Résumé (baseline pour l0-04) |
| O6 | `just check` | vert, hors ligne |

**Non testé** : le volume réellement **transféré** (non instrumentable — décision E-d) ;
la couverture d'autres sites que ceux du corpus (l0-03.5).
