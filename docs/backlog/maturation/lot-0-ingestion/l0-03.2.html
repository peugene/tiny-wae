[l0-03.2] — Le contrat du lot : manifestes et journal de run

Objectif

LE module-interface du lot : tout ce qui lit ou écrit un manifeste ou un journal passe par lui (l0-04, l0-05, l0-06 n'accèdent JAMAIS aux JSON directement).

Périmètre (fichiers nommés)

  • src/tiny_wae/adapters/manifests.py :
  • Schéma manifeste (schema_version: 1) : site_id, item_id, datetime, tile, sequence, platform, status (ingested | rejected_clouds | rejected_invalid | failed + cause pour failed), invalid_pct, cloud_pct, scl_class_counts (les 12 classes), processing_baseline, boa_offset_applied, raster_scale, raster_offset, grid_hash (hash epsg+origin_x+origin_y — la signature d'idempotence, décision chapeau), ⭐ assets_read (critère d'idempotence, décision E-d), content_hashes (par fichier : sha256(array.tobytes()) + CRS + transform + dtype — pas les octets du GeoTIFF), bytes_downloaded (STAC seul — donnée de rapport, jamais critère de gate), bytes_written (octets réellement écrits sur disque, somme des fichiers produits — la seule grandeur de volume qui soit exacte), duration_s, files: [], versions.
  • Schéma run.json (<data_root>/{site_id}/runs/{run_id}.json) : site_id, run_id, window, counters: {found_stac, skipped_scene_cloud, off_tile, found_tile, ingested, rejected_clouds, rejected_invalid, skipped, failed}, assets_read (somme des items du run — critère d'idempotence, E-d), bytes_downloaded (STAC seul), duration_s. Les 4 premiers viennent de l'enveloppe de l0-02 (le CLI les recopie) ; les 5 suivants sont produits par l'ingestion. Deux invariants de conservation vérifiés à l'écriture (exception typée sinon, décision E-a) : found_stac == skipped_scene_cloud + off_tile + found_tile et found_tile == ingested + rejected_clouds + rejected_invalid + failed + skipped.
  • API : write_manifest (atomique : tmp + rename, écrit EN DERNIER après les fichiers), read_manifest, list_for_site, last_datetime(site), write_run, read_run, list_runs(site), aggregate_counters(site) (fusion multi-runs, recouvrements dédupliqués par item_id).
  • Tests sur fixtures : corpus de manifestes synthétiques (réutilisé par l0-04.2 et l0-05) — livré dans tests/fixtures/manifests/ avec comptes CONNUS documentés.
