# [l0-05.2] — CLI update

## Objectif

Le run quotidien : pour chaque site, fenêtre depuis l0-05.1, `ingest`, résumé honnête.

## Périmètre (fichiers nommés)

- `src/tiny_wae/cli/update.py` (auto-découvert) : `update [--sites all] [--now …]` —
  une ligne par site sur STDERR, résumé final (« 25 sites, N avec du nouveau, M à jour,
  K échecs »). **Codes de sortie** (règle du chapeau l0-01, **obligatoire dans les 3 CLIs
  qui appellent l'amont**) : `OK=0` aucun échec · `FAILURE=1` au moins un échec avec au
  moins un succès, et site vierge (message nommant `backfill`) · ⭐ **`INCONCLUSIVE=3` si
  TOUS les échecs sont d'origine réseau et qu'aucun site n'a abouti** — c'est le CLI
  destiné au **cron**, celui que personne ne regarde tourner : une panne d'earth-search
  doit s'y distinguer d'un bug du pipeline.
- Rattrapage mensuel des retraitements tardifs : DOCUMENTÉ (README + une ligne dans la
  sortie du CLI le rappelant chaque 1er du mois via la date injectée) — non automatisé.
- Tests sur FixtureSource + corpus manifestes.

## Définition de « terminé »

- [ ] CLI + tests ; README complété (commande cron type + rattrapage).
