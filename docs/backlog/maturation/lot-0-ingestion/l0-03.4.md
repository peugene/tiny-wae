# [l0-03.4] — CLI ingest

## Objectif

Assembler : recherche (ou liste fournie) → pour chaque item : garde → SCL → verdict →
chips → manifeste. Relançable à l'infini.

## Périmètre (fichiers nommés)

- `src/tiny_wae/cli/ingest.py` (auto-découvert) : `ingest --acquisitions <envelope.json>`
  (chaînage CWL) ET `ingest --site A01 --from … --to …` (appelle StacSource). ⚠ **PAS
  d'option `--now`** (décision E-d : les deux formes portent une fenêtre explicite, l'option
  serait morte — `--now` vit sur `backfill` et `update`). Compteurs finaux sur STDERR (**found_stac /
  skipped_scene_cloud / off_tile / found_tile** puis ingested/rejected_*/skipped/failed +
  bytes + durée) ; `run.json` écrit via manifests API (les 4 compteurs de l'enveloppe y
  sont recopiés — cf. schéma l0-03.2, avec ses deux invariants de conservation).
- **Ordre invariant** (chapeau) : garde epsg → SCL seul → verdict → bandes 10 puis 20 m →
  ⭐ **garde nodata finale** (`chip_nodata_pct > chip_nodata_pct_max` → statut
  `rejected_nodata`, fichiers écrits **supprimés**, manifeste conservé — arbitrage n°3) →
  manifeste (dernier, atomique). Un rejet écrit un manifeste SANS chips.
- **Idempotence** : manifeste existant pour item_id **ET `grid_hash` identique** → skip
  compté. `grid_hash` différent (coordonnées corrigées) → ré-ingestion. `--force` →
  ré-ingestion inconditionnelle.
- **Retry/backoff au niveau requête** (paramètres `http_retries`/`http_backoff_s` de
  settings) sur STAC et lectures COG ; échec définitif → manifeste `failed` + cause,
  JAMAIS d'exception avalée. Un item en échec n'arrête pas les suivants. **Codes de
  sortie** (règle du chapeau l0-01) : `OK=0` · `FAILURE=1` si ≥ 1 failed avec au moins un
  succès · ⭐ **`INCONCLUSIVE=3` si TOUS les échecs sont d'origine réseau et aucun item
  n'a abouti** (amont injoignable ≠ bug — obligatoire aussi dans `backfill` et `update`).

- ⭐ **Smoke MINIMAL (ajout PO du 21/08 — le gate était creux)** : `scripts/smoke.py`
  cesse d'être un placeholder ici, pas six niveaux plus loin. Il exécute `ingest` de bout
  en bout sur un **double en mémoire du port `StacSource`** + un raster synthétique écrit
  par le script (aucun réseau, aucune fixture externe), et asserte : 3 fichiers produits,
  manifeste conforme, `assets_read > 0`. Le smoke **complet** (corpus réel, 2 modes,
  garde de contrat) viendra en l0-03.7 et le remplacera.
  *Motif : sans cela, dix fiches se valideraient sur un `just check` dont le volet smoke
  passe vert sans rien exécuter — conforme à la lettre de la règle « le gate appartient à
  la fiche qui le change », contraire à son esprit.*
