### Décisions d'ancrage (prises ici — ne pas rouvrir)

1. **Pas de fichier de sortie CWL obligatoire** (`outputs: []`), comme `ingest.cwl` : la spec
   CWL **interdit un `outputBinding.glob` commençant par `/`**, or `data_root` reçoit
   précisément un chemin absolu externe au sandbox. C'est une découverte de terrain de
   l0-06.1, déjà écrite dans `cwl/README.md` — ne la re-découvre pas, et dis dans le README
   que le succès se lit au code de sortie.
2. **Oracle O2 : l'amorçage est OBLIGATOIRE.** La fiche est explicite et deux formulations
   antérieures étaient fausses. Le protocole exact : (1) `ingest --site A01 --from J−20
   --to J−1` sur un `data_root` **vierge** ; (2) `cwltool update.cwl` — 1er run ; (3)
   `cwltool update.cwl` — 2e run. Ce que l'oracle mesure, c'est **le 2e run** :
   `ingested == 0` **et** `assets_read == 0`. ⚠ Sans amorçage, `update` rend `NoManifests` →
   exit 1 renvoyant vers `backfill` : le 1er run ne peut rien ingérer, par construction.
3. **Si le réseau est indisponible**, déclare O2 **non mesuré** en le disant — ⛔ jamais vert
   sans exécution. La validation statique (O1) reste, elle, dans le gate.
