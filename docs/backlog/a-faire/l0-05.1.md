## Objectif

Calculer la fenêtre du run incrémental d'un site, à sec.

## Périmètre (fichiers nommés)

« toutes les décisions tranchées »)** : **pas de nouveau module**. La fonction vit dans
**`core/windows.py`**, livré par l0-03.1 ; cette fiche l'**étend**, elle ne duplique rien.
`core/update_bounds.py` **n'existe pas**.

- `src/tiny_wae/core/windows.py` (extension) : `update_window_for_site(last_datetime,
  margin_days, now) -> Window | NoManifests` — borne basse = `last_datetime − margin`,
  borne haute = `now` (paramètre, horloge injectable) ; site sans manifeste → valeur
  typée `NoManifests` (le CLI en fera un exit 1 pointant vers backfill). La primitive
  générique `update_window(last, margin, now)` de l0-03.1 est **réutilisée telle quelle** ;
  cette fonction n'ajoute que la lecture du `last_datetime` via l'API manifests et le cas
  `NoManifests`.
- Tests à sec sur manifestes fixtures (corpus l0-03.2) : dernier jour, marge, site vierge,
  statuts rejetés comptés dans `last_datetime`.
