- ⭐ **Arbitrage n°1 (21/08) — `raster:bands` est une propriété PAR ASSET, pas par item** :
  mesuré, les 10 bandes de réflectance portent `scale 0.0001 / offset −0.1`, mais `aot` et
  `wvp` portent `0.001 / 0` et `scl` n'en a **aucun**. Le contrat expose donc
  `radiometry: dict[str, tuple[float, float] | None]` (clé d'asset → scale/offset), pas
  deux scalaires. C'est la **traçabilité radiométrique promise au Lot 1** : un contrat
  lossy ici se paierait par une ré-lecture complète plus tard.
  Round-trip JSON de l'ensemble.
- `core/envelope.py` : l'enveloppe versionnée du chapeau (`schema_version=1`, counters,
  items) + round-trip. **Counters exacts** : `found_stac`, `skipped_scene_cloud`,

  L'enveloppe **vérifie elle-même** `found_stac == skipped_scene_cloud + off_tile +
  found_tile` et `found_tile == len(items)` à la construction (exception typée sinon).
- `src/tiny_wae/adapters/stac.py` : port `StacSource` (protocole : `search(site, window)
  -> Envelope`) + `EarthSearchSource` (pystac-client). Filtres : bbox du chip TOUJOURS +

  (compté `off_tile`). **Garde href : pour les clés d'assets MAPPÉES uniquement, refuser
  tout `s3://`** (les assets non mappés des S2C sont ignorés sans erreur).
- Tests : fixtures enregistrées dans `tests/fixtures/stac/` — **cinq** : (1) l'item gelé
  `S2B_31TGJ_20230315_0_L2A`, (2) l'item S2C `S2C_31TGJ_20260513_0_L2A` (schéma d'assets
