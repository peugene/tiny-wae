  • ⭐ Arbitrage n°1 (21/08) — raster:bands est une propriété PAR ASSET, pas par item : mesuré, les 10 bandes de réflectance portent scale 0.0001 / offset −0.1, mais aot et wvp portent 0.001 / 0 et scl n'en a aucun. Le contrat expose donc radiometry: dict[str, tuple[float, float] | None] (clé d'asset → scale/offset), pas deux scalaires. C'est la traçabilité radiométrique promise au Lot 1 : un contrat lossy ici se paierait par une ré-lecture complète plus tard. Round-trip JSON de l'ensemble.
  • core/envelope.py : l'enveloppe versionnée du chapeau (schema_version=1, counters, items) + round-trip. L'enveloppe vérifie elle-même found_stac == skipped_scene_cloud + off_tile + found_tile et found_tile == len(items) à la construction (exception typée sinon).
  • src/tiny_wae/adapters/stac.py : port StacSource (protocole : search(site, window) -> Envelope) + EarthSearchSource (pystac-client). Filtres : bbox du chip TOUJOURS + eo:cloud_cover < scene_cloud_max (compté skipped_scene_cloud) + tuile de référence (compté off_tile).
